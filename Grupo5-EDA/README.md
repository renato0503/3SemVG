## Objetivo

Entender como as pessoas **lidam com o gasto por impulso e com as dívidas**, o peso da **culpa e da vergonha** e se um **espaço de apoio entre pares, anônimo e sem julgamento** (inspirado no modelo de Alcoólicos Anônimos, adaptado a finanças) faz sentido para elas.

## Hipótese

Muitas pessoas **gastam por impulso**, têm dificuldade de **falar sobre dívidas por vergonha** e **não encontram apoio** — o que faz o ciclo do endividamento se repetir. Um **espaço anônimo de acolhimento entre pares** pode reduzir esse isolamento e ajudar a pessoa a buscar ajuda.

> A hipótese existe para ser testada — se os dados mostrarem o contrário, isso é um resultado, não um erro.

> ⚠️ **Tema sensível.** Este grupo trata de **saúde mental + dinheiro**. Fale com **respeito e empatia**, garanta o **anonimato** e **nunca julgue**. O EDA **não é tratamento médico**: é **apoio e acolhimento entre pares** e pode **encaminhar** para serviços de saúde (CVV 188, CAPS, UBS). Se a pessoa se emocionar, ofereça uma pausa e não insista.

## Ideia proposta pelo grupo

**"Espaço de reabilitação para gastadores compulsivos."**

O grupo propõe um **espaço de acolhimento** para pessoas que têm dificuldade em controlar os gastos. A inspiração é o modelo dos **grupos de apoio entre pares** (como Alcoólicos Anônimos), adaptado ao tema das **finanças**: encontros regulares, **anonimato**, **sem julgamento** e apoio mútuo entre pessoas que vivem a mesma situação. A proposta é oferecer escuta, partilha de experiências e encaminhamento para ajuda profissional quando necessário.

## Questionário proposto (rascunho a validar)

**Título:** Endividados Anônimos (EDA) — gastos, dívidas e apoio
**Formato:** 9 perguntas (sim/não, múltipla escolha e frequência).

### Perguntas (1 a 9)

1. Você já fez compras que **não estavam planejadas** e depois se arrependeu? — ( ) Sim, muitas vezes ( ) Sim, algumas vezes ( ) Raramente ( ) Nunca
2. Com que frequência você compra por impulso quando está estressado(a), triste ou ansioso(a)? — ( ) Sempre ( ) Frequentemente ( ) Às vezes ( ) Raramente ( ) Nunca
3. Você costuma **esconder compras ou dívidas** de familiares? — ( ) Sim ( ) Não ( ) Às vezes
4. As dívidas já **afetaram suas relações familiares**? — ( ) Sim ( ) Não ( ) Não sei dizer
5. Você já se sentiu **culpado(a) ou envergonhado(a)** depois de gastar? — ( ) Sim ( ) Não ( ) Às vezes
6. Com que frequência as dívidas **tiram sua tranquilidade**? — ( ) Sempre ( ) Frequentemente ( ) Às vezes ( ) Raramente ( ) Nunca
7. Você já procurou algum tipo de **ajuda** (grupo, terapia ou orientação financeira) para lidar com gastos ou dívidas? — ( ) Sim ( ) Não
8. O **anonimato** seria importante para você participar de um grupo de apoio? — ( ) Muito importante ( ) Importante ( ) Pouco importante ( ) Não
9. Você participaria de um **espaço de acolhimento** para pessoas com dificuldade de controlar os gastos? — ( ) Sim ( ) Não ( ) Talvez

### Pontos de atenção na validação (Parte 2)

| # | Problema | Ação sugerida |
|---|---|---|
| 9 | Pergunta de **futuro/hipótese** ("participaria") | Reescrever para **comportamento passado** ou intenção no espaço 1–5 |
| 7 | **Pergunta dupla** (grupo + terapia + orientação numa só) | Dividir ou escolher o foco |
| 8 | Opinião sobre anonimato **sem escala** | Levar para escala 1–5 (nada importante → muito importante) |
| 2, 6 | Boas perguntas de **frequência** | Manter e reduzir a escala 1–5 |
| 1, 3, 4, 5 | Boas perguntas de **comportamento/sentimento** | Manter (atenção ao tom acolhedor) |
| — | **Tema sensível** e sem espaço para fala | Sem texto livre; verbatim vai para o **áudio** com código |
| — | Risco de o entrevistado se sentir **julgado** | Reforçar anonimato e linguagem neutra na abordagem |

> **Diagnóstico:** o questionário já capta o essencial (impulso, esconder, culpa, vergonha e interesse em apoio). O ajuste principal é **trocar a pergunta de intenção (9) por comportamento**, **dividir a 7** e padronizar tudo na **escala 1–5**. Como é um tema sensível, o **áudio com código** é indispensável para dar contexto ao que a escala não mostra.

## Protocolo de coleta (todos os grupos)

Formulário único em **3 camadas** + **código de correlação**:

| Camada | Quem faz | O que registra |
|---|---|---|
| 1 · Perfil | Entrevistador (observação, **não pergunta**) | Faixa etária, sexo, classe social, raça |
| 2 · Respostas | Entrevistador (marca no app) | Opção mais próxima, em escala 1–5 |
| 3 · Áudio | Outro aluno | WhatsApp: **código** + ideias principais (20–40s) |

**Código:** `G<grupo>-<nº da resposta>` — ex.: `G5-014`. Igual na tela do formulário e no início do áudio. É o que permite cruzar **quanti × quali** na análise.

**Em campo:** 1 celular para o formulário (entrevistador) + 1 celular gravando áudio no WhatsApp.
