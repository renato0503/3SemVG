## Objetivo

Descobrir como as famílias de **Várzea Grande** organizam (ou não) o **orçamento familiar**, se sentem falta de uma forma simples de **encontrar economia nas compras do mercado** e se confiariam em uma **plataforma gratuita patrocinada pelo mercado local** que lê o **cupom fiscal** e ajuda a construir uma **reserva financeira**.

## Hipótese

A maior dor da família é **não saber para onde o dinheiro do mês está indo** e **não conseguir guardar reserva**; além disso, as pessoas **perdem oportunidades de economia** por não comparar preços nem usar o cupom fiscal — e aceitariam um app **gratuito** se o **mercado local fosse o patrocinador**, desde que os dados fossem usados com transparência.

> A hipótese existe para ser testada — se os dados mostrarem o contrário, isso é um resultado, não um erro.

## Ideia proposta pelo grupo

Uma **plataforma free** que:

- **organiza a renda familiar** (o que entra, o que sai);
- **encontra oportunidades de economia** (comparação de preços e ofertas);
- **constrói uma reserva financeira** aos poucos;
- **lê o cupom fiscal do mercado regional**;
- é **somente para cidadãos várzea-grandenses**, com o **mercado como patrocinador** da plataforma.

> **Importante:** o **patrocínio do mercado local** e a **leitura automática do cupom fiscal** são **hipóteses/desafios a validar** — não são fatos dados. O teste em campo é justamente entender se isso faz sentido para as pessoas.

## Questionário proposto (rascunho a validar)

**Título:** Vida no Controle — orçamento familiar, economia e cupom fiscal
**Formato:** 9 perguntas (sim/não, múltipla escolha e frequência).

1. Você faz o controle do orçamento da sua família? — ( ) Sim, sempre ( ) Às vezes ( ) Nunca
2. Você sabe quanto a sua família gasta por mês no mercado? — ( ) Sim ( ) Mais ou menos ( ) Não
3. Você costuma comparar preços entre mercados antes de comprar? — ( ) Sempre ( ) Às vezes ( ) Nunca
4. Você já deixou de comprar algo por não saber onde estava mais barato? — ( ) Sim ( ) Não
5. Você consegue guardar dinheiro todo mês? — ( ) Sempre ( ) Às vezes ( ) Nunca
6. Você já precisou usar crédito ou empréstimo por falta de reserva? — ( ) Sim ( ) Não
7. Você guarda ou confere o cupom fiscal das compras do mercado? — ( ) Sim ( ) Não
8. Você usaria um aplicativo gratuito que organiza a renda e mostra onde economizar? — ( ) Sim ( ) Não ( ) Talvez
9. Você confiaria em um app gratuito bancado pelo mercado local? — ( ) Sim ( ) Não ( ) Talvez

> Falta validar o **recorte geográfico** (mora em Várzea Grande?) e o uso real do **cupom fiscal**.

### Pontos de atenção na validação (Parte 2)

| # | Problema | Ação sugerida |
|---|---|---|
| 8, 9 | Perguntas de **futuro/hipótese** ("você usaria/confiaria") | Reescrever para **comportamento passado** |
| 2 | Risco de virar **pedido de valor exato** de gasto | Focar em **percepção**, nunca em números de renda |
| 6 | **Pergunta sensível** (crédito/empréstimo) | Deixar opção neutra e tratar no áudio, sem expor |
| 7 | Boa pergunta, mas **genérica** | Desdobrar no bloco de **cupom fiscal** (guardar × conferir preços) |
| 1, 3, 5 | Boas perguntas (frequência e comportamento) | Manter |
| — | Sem **recorte geográfico** explícito | Incluir triagem "mora em Várzea Grande?" |
| — | Sem **verbatins** | Usar **áudio com código** para as falas |

> **Diagnóstico:** o rascunho é enxuto e já tem boas perguntas de comportamento, mas **não mede o interesse no patrocínio do mercado nem o uso do cupom fiscal** com profundidade, e ainda tem **perguntas de intenção (8 e 9)**. O ajuste principal é trocar intenção por comportamento, detalhar cupom fiscal e manter tudo longe de valores exatos de renda.

## Protocolo de coleta (todos os grupos)

Formulário único em **3 camadas** + **código de correlação**:

| Camada | Quem faz | O que registra |
|---|---|---|
| 1 · Perfil | Entrevistador (observação, **não pergunta**) | Faixa etária, sexo, classe social, raça |
| 2 · Respostas | Entrevistador (marca no app) | Opção mais próxima **1–5** (sem resposta aberta) |
| 3 · Áudio | Outro aluno | WhatsApp: **código** + falas principais (20–40s) |

**Código:** `G<grupo>-<nº da resposta>` — ex.: `G6-014`. Igual na tela do formulário e no início do áudio. É o que permite cruzar **quanti × quali** na análise.

**Em campo:** 1 celular para o formulário (entrevistador) + 1 celular gravando áudio no WhatsApp.
