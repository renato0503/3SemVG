## Objetivo

Descobrir se a **dificuldade de organizar contas e datas** e a **falta de orientação financeira presencial** são as maiores dores de famílias com o orçamento apertado — e validar se um **programa do governo com atendimento presencial, sistema inteligente e bolsa-incentivo** faz sentido para esse público.

## Hipótese

A maior dor é a **desorganização das contas e o aperto do orçamento**; as pessoas **já adiaram ou deixaram de pagar algo por não saber organizar datas**, e **buscariam ajuda** se ela fosse oferecida de forma presencial e confiável.

> A hipótese existe para ser testada — se os dados mostrarem o contrário, isso é um resultado, não um erro.

3. "Às vezes a gente perde o controle das contas e das datas, né? Podemos te fazer 5 perguntinhas sobre isso?"
4. "Respondo no meu celular mesmo. Pode ser?"

## Ideia proposta pelo grupo

> "Programa do governo no qual as pessoas vão até o local **presencialmente** e o governo fornecerá **profissionais para auxiliar** as pessoas, além de um **sistema inteligente** que as ajudará a **organizar as contas e datas**, além de um incentivo de uma **bolsa** para que os cidadãos tenham um empurrãozinho para organizar a vida financeira."

Em resumo, a ideia tem **três peças**:

1. **Atendimento presencial** — um posto físico onde profissionais ajudam a organizar a vida financeira.
2. **Sistema inteligente** — ferramenta que organiza contas e datas.
3. **Bolsa-incentivo** — um empurrão para quem decide colocar as contas em ordem.

## Questionário proposto pelo grupo (rascunho a validar)

**Título:** Dinheiro na Mão — organização das contas e apoio para a vida financeira
**Formato:** 9 perguntas (sim/não, múltipla escolha e frequência).

### Perguntas (1 a 9)

1. Você é a pessoa que cuida das contas da sua casa? — ( ) Sim, sozinho(a) ( ) Divido com outra pessoa ( ) Não, outra pessoa cuida
2. Como está a situação financeira da sua casa hoje? — ( ) Muito apertada ( ) Apertada ( ) Equilibrada ( ) Tranquila
3. Com que frequência alguma conta do mês fica atrasada? — ( ) Nunca ( ) Às vezes ( ) Frequentemente ( ) Sempre
4. Você costuma anotar ou planejar as contas antes de pagar? — ( ) Sempre ( ) Às vezes ( ) Nunca
5. Você já perdeu uma data de vencimento por esquecimento? — ( ) Sim ( ) Não
6. Você já buscou ajuda ou orientação para organizar as suas finanças? — ( ) Sim ( ) Não
7. Você acha difícil encontrar orientação financeira confiável? — ( ) Sim ( ) Às vezes ( ) Não
8. Você usaria um atendimento presencial gratuito para organizar suas contas? — ( ) Sim ( ) Não ( ) Talvez
9. Você se interessaria por uma bolsa-incentivo para quem organiza a vida financeira? — ( ) Sim ( ) Não ( ) Talvez

### Pontos de atenção na validação (Parte 2)

| # | Problema | Ação sugerida |
|---|---|---|
| 8, 9 | Perguntas de **futuro/intenção** ("você usaria/se interessaria") | Reescrever para **comportamento passado** ou utilidade percebida |
| 8 | **Pergunta dupla/hipotética** (presencial + gratuito) | Separar presencial de "gratuito" e focar em um só |
| 4, 2 | Alternativas **sem escala** (níveis fixos) | Converter para **escala 1–5** com polos rotulados |
| 6, 7 | Misturam **ajuda buscada** e **dificuldade percebida** | Manter, mas separar em perguntas distintas no app |
| — | Sem **campo qualitativo** | Adicionar áudio com **verbatim** ("conte como foi a última vez") |
| 2 | Pergunta sobre situação financeira pode gerar desconforto | Perguntar em tom leve, sem pedir valores |
| — | Nenhuma pergunta sobre **datas de vencimento** | Incluir percepção de esquecimento de datas |

> **Diagnóstico:** o questionário é um bom ponto de partida e já evita pedir valores de renda/dívida. O ajuste principal é **trocar as perguntas de intenção (8 e 9) por utilidade percebida e comportamento passado**, converter alternativas em **escala 1–5** e incluir o **áudio com o verbatim**.

## Protocolo de coleta (todos os grupos)

Formulário único em **3 camadas** + **código de correlação**:

| Camada | Quem faz | O que registra |
|---|---|---|
| 1 · Perfil | Entrevistador (observação, **não pergunta**) | Faixa etária, sexo, classe social, raça |
| 2 · Respostas | Entrevistador (marca no app) | Escala 1–5 de cada uma das 20 perguntas |
| 3 · Áudio | Outro aluno | WhatsApp: **código** + ideias principais (20–40s) |

**Código:** `G1-<nnn>` — ex.: `G1-014`. Igual na tela do formulário e no início do áudio. É o que permite cruzar **quanti × quali** na análise.

**Em campo:** 1 celular para o formulário (entrevistador) + 1 celular gravando áudio no WhatsApp.
